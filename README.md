# Ant Up!

Multiplayer arcade stealth game where ants steal food from a barbecue and bring it back to their colony.

This repository currently contains a private playtest. Gameplay is not complete.

## Running the playtest

1. Download the latest release
2. Extract and run the executable
3. Open Steam and ensure you are logged in
4. Host or join a lobby from the main menu

WASD – Move  
Mouse – Look  
Space – Jump (if applicable)  
E – Interact
